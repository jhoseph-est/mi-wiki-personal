# Caja de seguridad con huella digital
- Arduino Mega 2560 R3
- Módulo RTC DS3231
- Lector de memoria Micro SD Card 74LVC125A
- Lector de huella digital AS608 - 300H
- Display Alfanumérico LCD 1602
- Pulsador PBS33B Redondo de 2 pines 12mm
- Servomotor SG90
- SIM800L
- sensor magnético

## lista de pines
sensor magnetico (gnd, pin 47)
servo motor (gnd, pin 49)
boton verde (gnd, pin 48)
boton azul (gnd, pin 46)
boton rojo (gnd, pin 44)
huella (gnd, vcc, TX3(14), RX3(15))
reloj (gnd, vcc, sda(20), scl(21))
memoria (gnd, vcc, mosi(50), miso(51), sck(52), cs(53))
llamada (gnd, vcc(4v), rx2(17), tx2(16))
lcd (gnd, vcc, sda(20), scl(21))
